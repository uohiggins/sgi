# Solicitudes a uoh-ui

Cuando `uoh-ui` no cubre una necesidad de SGI, se crea un componente local derivado (`src/app/shared/uoh-derived/`, selector `uohx-`) y se documenta aquí lo que falta, para que el diseñador pueda incorporarlo a la librería. Cada solicitud usa la plantilla [_plantilla.md](./_plantilla.md).

Regla completa: sección "Uso de la librería uoh-ui" de `frontend-instruccions.md`.
